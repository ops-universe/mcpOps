# Harness and CLI

Run node src/cli.mjs request 2025-11-25 with a JSON request on stdin. Other commands: tool, inventory, governance, security, redact, test. Governance accepts {inventory,request,policy}; policy must be supplied independently by a trusted operator. Test accepts {request,revision,fixture:{response,delayMs},timeoutMs}; response is a JSON string. Fixture data only, no callbacks or external connections. Text-only tool results are a deliberate subset; unsupported content is not necessarily invalid MCP. Security findings are heuristics only, not verified vulnerabilities. Redaction is intentionally lossy, removes all arbitrary field names and values, and does not promise to preserve usable payloads. CLI exit 1 denotes rejected validation or denied simulation, 2 invalid invocation. Review decisions are not execution grants.

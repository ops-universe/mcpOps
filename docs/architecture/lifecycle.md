# Lifecycle inspection

Official SDK references: https://ts.sdk.modelcontextprotocol.io/v2/protocol-versions and https://ts.sdk.modelcontextprotocol.io/v2/migration/support-2026-07-28 . Legacy initialization reference: https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle . The offline checker accepts a pinned 2025-11-25 initialization, response, initialized notification and subsequent tools-only request/response transcript. It is deliberately stricter than general protocol semantics, does not negotiate versions, does not handle notifications or ping during the handshake, and does not establish interoperability. Modern discovery and metadata contracts remain pending. CLI: node src/cli.mjs legacy-transcript; node src/cli.mjs permissions; node src/cli.mjs configuration. JSON on stdin. Permission comparison is operator-declared, not actual OS authorization.

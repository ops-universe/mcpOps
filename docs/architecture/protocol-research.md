# Protocol references

Official specification: https://modelcontextprotocol.io/specification/ ; SDK: https://ts.sdk.modelcontextprotocol.io/ ; Inspector: https://github.com/modelcontextprotocol/inspector . Initial profiles select a common structural subset only; version negotiation, capability semantics, schema evaluation and wire compatibility are not implemented. Inspector offers interactive inspection; mcpOps prioritizes offline governance and reproducible evidence.
